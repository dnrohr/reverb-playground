# Reverb Playground v0.1.0-alpha.1

This is the first public alpha of Reverb Playground: an open-source visual
instrument for constructing, hearing, and inspecting algorithmic reverbs.

## Supported system and formats

- Windows 10 or 11, x64
- Standalone application
- VST3 stereo effect
- Microsoft Evergreen WebView2 Runtime
- 32-bit floating-point audio processing at host sample rates validated from
  22.05 kHz through 384 kHz, including 44.1, 48, and 96 kHz

The download is a portable ZIP. Verify its adjacent SHA-256 file before
extracting, then follow the [installation guide](https://github.com/dnrohr/reverb-playground/blob/v0.1.0-alpha.1/docs/windows-package-installation.md).

## Major capabilities

- Editable mono-cable schematic with stereo input and output blocks
- Explicit Delay, Allpass, Gain, Sum, low-pass, modulation, envelope, and gate primitives
- Barr-inspired reference, causal reverse-envelope, and level-gated factory patches
- Legal delayed feedback, invalid algebraic-cycle rejection, safety limits,
  runaway-output muting, and explicit recovery
- Continuous audible edits, undo/redo, clipboard operations, patch save/load,
  and host-project state restoration
- LFO and Scale / Offset control mapping
- Impulse capture, stereo response navigation, RT60/landmark overlays,
  feedback-loop inspection, live energy, diagnostics, and contextual teaching

## Known alpha limitations

- This release supports Windows x64 only. macOS, Linux, AAX, Audio Unit, and
  standalone builds for other platforms are not provided.
- The VST3 reports 64-bit sample processing as unsupported and processes
  32-bit floating-point audio.
- External alpha usability testing is deferred: the written M7.5 protocol and
  automated accessibility checks are complete, but the required three non-implementer sessions have not yet run. This prerelease is therefore not
  represented as externally usability- or accessibility-validated.
- Interactive host validation covered Tracktion pluginval, Steinberg's VST3
  validator, and JUCE AudioPluginHost. Other DAWs may expose host-specific behavior.
- “Causal Reverse Envelope” creates a rising-energy impression in real time;
  it does not reverse samples, use lookahead, or create pre-echo.
- Factory patches currently cover Barr/reference, causal reverse-style, and
  level-gated families. Short-room and Bloom-like families remain deferred.

## Feedback and source

Report reproducible defects or documentation problems through
[GitHub Issues](https://github.com/dnrohr/reverb-playground/issues). Include the
version and 12-character commit displayed in the editor, Windows version, host
and version, audio settings, and the smallest safe reproduction you can share.
Do not attach proprietary ROMs, commercial impulse responses, personal data, or
host projects you cannot redistribute.

Source, license, build instructions, and full documentation are available in
the [repository](https://github.com/dnrohr/reverb-playground).
