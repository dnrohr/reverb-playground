# Reverb Playground v0.1.0-alpha.2

Alpha.2 turns the development since alpha.1 into one coherent workflow: learn
the signal vocabulary, build and tune an editable reverb, move between parent
and nested schematics, compare or diagnose without hidden graph mutation, and
recover safely when a session fails.

## Supported system and formats

- Windows 10 or 11, x64
- Standalone application
- VST3 stereo effect
- Microsoft Evergreen WebView2 Runtime
- 32-bit floating-point audio processing at host sample rates validated from
  22.05 kHz through 384 kHz, including 44.1, 48, and 96 kHz

The download is a portable ZIP. Verify its adjacent SHA-256 file before
extracting, then follow the [installation and removal guide](https://github.com/dnrohr/reverb-playground/blob/v0.1.0-alpha.2/docs/windows-package-installation.md).
The editor and `build-info.json` identify the tagged source with the same
12-character commit.

## Changes since alpha.1

- Added Gravity Diffusion, Safe Parallel Shimmer, Split-Feedback Shimmer,
  Reverse Cosmic Shimmer, Dense Figure Eight, and Four-Line FDN factory designs,
  plus visible Macro, Curve Mapper, and bounded Pitch Shift building blocks.
- Added standalone WAV/AIFF/FLAC playback, looping, seeking, Wet/Dry comparison,
  and deterministic processed WAV export.
- Rebuilt the editor around compact responsive docks, contextual inspection,
  searchable offline Help, consistent module vocabulary, and a compact audition
  and measurement drawer.
- Added explicit Sum assistance, collapsible groups, reusable subpatches,
  expandable Matrix compounds, live nested editing, cable routing, alignment,
  distribution, bounded group layout, and reversible block orientation.
- Added temporary isolate/mute/bypass diagnosis, immutable A/B snapshots,
  cumulative assisted tuning, and revision-correct parameter synchronization.
- Added private local Windows crash reports, opt-in last-known-valid standalone
  recovery that starts muted, candidate quarantine, and global Ctrl+Shift+M
  Emergency Mute that also cancels or refuses export.
- Fixed stale build identity, startup/window-fill behavior, host latency
  reporting, extreme host-rate preparation, stale control layers, hierarchy
  selection/context repair, and mixed-size layout overlap.

## Compatibility and migration

Schema-v1 and schema-v2 patches still load through deterministic migration.
Legacy Pitch Shift values outside the supported one-octave range are clamped
with a migration warning. Patches without an explicit quality policy use the
safe default; hierarchy, grouping, cable routes, and block orientation are
presentation metadata and do not replace the authoritative primitive graph.
VST3 host projects remain authoritative and are never replaced by standalone
autosave recovery. Save a copy of important work before moving it between alpha
versions.

## Crash reports and privacy

Crash summaries and matching Windows minidumps are stored only in the local
per-user application-data folder. Summaries are bounded and exclude source
audio, audio samples, complete patch JSON, user document paths, and host-project
content. Minidumps can contain process memory and should be reviewed before
sharing. Nothing is uploaded automatically. See the [crash recovery and
Emergency Mute contract](https://github.com/dnrohr/reverb-playground/blob/v0.1.0-alpha.2/docs/crash-recovery-and-emergency-safety.md).

## Known alpha limitations

- Windows x64 is the only published platform. Builds are not code-signed.
- The VST3 supports 32-bit, not 64-bit, floating-point sample processing.
- The required three non-implementer sessions have not yet run. Automated
  accessibility/preflight checks pass, but this prerelease is not represented
  as externally usability- or accessibility-validated.
- Dense-reverb comparative listening notes from external listeners remain
  outstanding; measured qualification is not a substitute for those judgments.
- Exact release qualification covers pluginval and Steinberg's VST3 validator.
  Other DAWs can expose host-specific behavior.
- Reverse-style patches create causal rising-energy impressions. They do not
  reverse future samples, use lookahead, or reproduce a proprietary algorithm.
- Keith Barr/Alesis references describe inspiration and structural study. This
  release contains no ROM data and does not claim circuit- or firmware-exact
  provenance.

## Feedback and source

Report reproducible defects through [GitHub Issues](https://github.com/dnrohr/reverb-playground/issues).
Include the version and 12-character commit displayed in the editor, Windows
version, host/audio settings, crash incident ID when relevant, and the smallest
safe reproduction you can share. Do not attach private host projects, source
audio, or minidumps you have not reviewed.

Source, AGPLv3-only license, build instructions, documentation, third-party
notices, and asset provenance are available in the repository.
