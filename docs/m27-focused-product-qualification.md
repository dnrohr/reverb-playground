# Focused diagnosis and comparison qualification

M27.5 validates the focused workspace after the M25 shell, M26 construction
tools, and M27 audition/comparison refinements are combined. The qualification
uses Barr Reference, Four-Line Dense Room, and Reverse Cosmic Shimmer because
they span a small teaching graph, a dense feedback matrix, and a large
pitch-shifted reverse architecture.

## Interactive journeys

| Architecture | Workspace emphasis | Qualified workflow | Result |
| --- | --- | --- | --- |
| Barr Reference | Balanced | Select Tank 1, isolate its audible paths, inspect the explicit temporary state, and verify measurement offers capture with the overlay | The selected block, highlighted path, clear-isolate action, and “patch and export unchanged” disclosure agree |
| Four-Line Dense Room | Create Focus | Collapse the side docks, inspect the authoritative 4×4 Matrix Mixer summary, then expand it | The summary disappears and the unchanged 16 Gain / 12 Sum primitive network becomes authoritative on screen |
| Reverse Cosmic Shimmer | Learn & Inspect | Open Learn, focus Reverse Grains, and follow the highlighted causal pitch-return path | Teaching text, highlighted blocks/cables, and the executable graph describe the same buffered reverse-grain topology |
| Reverse Cosmic Shimmer versus Barr Reference | Learn & Inspect | Capture A and B, audition A, inspect structural differences, and request matching without response probes | Raw switching works; matching is disabled with the exact instruction to capture an impulse for each graph |
| A/B comparison | Compact 640×400 | Keep the comparison open while resizing to the minimum supported viewport | The complete viewport remains 640 pixels wide with no horizontal document overflow; the panel scrolls internally |

The first pass exposed a graph-truth presentation defect: an isolate or compound
expansion status survived loading another factory even though the underlying
temporary state had already cleared. Factory selection now clears that transient
graph-action status before identifying the newly active patch. A source-contract
regression test protects the ordering.

## Automated coverage

The full Release verifier covers graph serialization, every catalog factory,
host-state restoration, deterministic export, selected-loop export, preview-only
audition state, A/B gain isolation, matrix expansion, compact layout, safety,
accessibility, documentation, provenance, and release contracts. The local M27.5
run passes 171 web tests, 25 repository tests, and 252 native/CLI tests.

The temporary overlay remains outside patch files, host state, undo history,
clipboard, factory identity, and ordinary WAV export. Bypass is offered only for
eligible processing blocks and its graph transformation refuses algebraic
cycles. Stereo I/O has no bypass action. Valid and refused A/B matching are
covered by the comparison tests; the browser fixture intentionally demonstrates
the honest no-probe refusal because it has no native impulse bridge.

## Release boundary

The exact source commit, Windows package checksum, pluginval result, Steinberg
validator result, and clean-main CI run are recorded with the final qualification
after the implementation commit is immutable. This prevents a dirty-worktree
binary or stale embedded commit from being presented as the release candidate.
