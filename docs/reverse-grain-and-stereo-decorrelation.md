# Reverse grains and deterministic stereo decorrelation

M13.1 extends the public mono Pitch Shift primitive with an explicit saved
starting phase. It enables the later Reverse Cosmic Shimmer graph to use two
ordinary mono shifters whose grain boundaries differ, while keeping reset and
session recall deterministic.

## Public contract

Pitch Shift now has five visible parameters: Semitones, Grain, Overlap,
Direction, and Phase. Phase is a static `0.000...0.999 cycle` offset with a
`0.001` step and default `0`. It does not add a cable, oscillator, random seed,
stereo processor, feedback path, or modulation source. The two internal read
heads are always separated by one half-cycle.

The reference stereo pairing is two visible mono instances at phase `0.000`
and `0.373`. Both consume the same signal when a designer wants decorrelation
alone, or separate left/right signals when the topology already has stereo
differences. The unusual non-quarter-cycle offset avoids repeatedly coincident
boundaries without claiming statistical randomness.

Reset restores each instance to its saved phase. Identical configuration,
input, block partition, and reset therefore remain bit-identical. Changing
Phase or Direction uses the existing 20 ms state transition; no audio-thread
allocation or topology discovery is introduced.

## What reverse means

In forward mode the delay slope is `1 - ratio`; in reverse mode it is
`1 + ratio`, so samples inside each finite grain are read in descending order.
Every read still comes from the prepared history ring. Both modes report the
same worst-case 600 ms latency, and neither can produce wet output before the
input plus that latency.

This is reverse-grain pitch shifting. It is not whole-tail reversal,
reverse-impulse convolution, offline reversal, or a claim that the complete
reverb precedes the source. Reverse grains can reshape local attacks inside a
causal later response; a causal-rise front end is still needed for the larger
reverse-style perceptual gesture.

## Checked measurements

[`pitch-shift-validation-v1.json`](../artifacts/measurements/pitch-shift-validation-v1.json)
is generated by the Release validation executable and covers every qualified
rate. Its `reverseGrain` object records the `0.000/0.373` pair, output
correlation, exact repeatability, pre-latency causality, and a deterministic
137 ms transient train analyzed with a 2 ms smoothed absolute envelope.

| Rate | Pair correlation | Forward peak envelope step | Reverse peak envelope step | Normalized envelope difference |
|---:|---:|---:|---:|---:|
| 44.1 kHz | -0.004258 | 0.006377 | 0.006377 | 1.3580 |
| 48 kHz | 0.001705 | 0.005862 | 0.005862 | 1.3500 |
| 96 kHz | -0.000083 | 0.002939 | 0.002939 | 1.3497 |

The peak steps are effectively equal for this sparse fixture, so the evidence
supports the roadmap's **reshape** branch rather than claiming reduced attacks.
The large normalized envelope difference shows that forward and reverse place
that transient energy differently in time. Correlation stays near zero and
well below the checked absolute `0.95` ceiling.

The same report retains ±15-cent octave tolerance checks for each direction,
measured Release CPU below 10%, exact rate-derived storage/latency, and disclosed
folded alias energy. Separate executable tests retain finite forward/reverse
delayed-feedback renders, topology crossfade, numerical latch, emergency mute,
state-clearing recovery, and silence after recovery at 44.1, 48, and 96 kHz.

## Compatibility and inspection

Native graph compilation accepts the released four-parameter Pitch Shift as
phase `0`. The web loader migrates those schema-v2 nodes to the new fifth
parameter, after which save writes the current complete representation. Invalid
phase values or units are rejected. Native host/plugin state tests restore a
non-default `0.373` value exactly.

The inspector displays Phase numerically and offsets both illustrative grain
markers. Reduced-motion mode freezes them at the saved phase positions. These
markers communicate configuration only; audio tests and the checked report are
authoritative for causality, pitch, and decorrelation.

## Scope boundary

M13.1 supplies the reusable primitive and its evidence. It does not ship a new
reverb preset. M13.2 will combine two reverse-grain voices with the existing
causal-rise, split-feedback, damping, modulation, and unequal stereo diffusion
vocabulary using only visible public blocks.
