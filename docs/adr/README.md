# Architecture decision records

Architecture decision records (ADRs) capture choices that constrain implementation, licensing, distribution, or the user-visible graph model.

| ADR | Decision | Status |
|---|---|---|
| [0001](0001-primary-stack-and-delivery-target.md) | Primary stack and initial delivery target | Accepted |

An ADR is changed by adding a superseding ADR rather than silently rewriting the original decision. Corrections and clarifications that do not change the decision may edit the existing record.
