# Factory patches

These schema-v2 documents are generated by `scripts/generate_factory_patches.mjs` from mathematical parameters and project-defined public primitives. They contain no third-party preset dump, program ROM, captured impulse response, or recorded audio.

- `causal-reverse-envelope.rvp.json` builds a causal rising response from visible increasing Delay/Gain branches.
- `level-gated-room.rvp.json` builds a diffuse room with a visible Envelope Follower and stereo Hold Gates.

Run the generator from the repository root after intentionally changing a factory topology:

```powershell
node scripts/generate_factory_patches.mjs
```

Native tests load the checked-in files, validate/compile/round-trip them, measure their impulse envelopes at 44.1/48/96 kHz, and stress them with bounded stereo noise. Browser tests independently parse them through the editor schema and require every processor to be a visible module.
