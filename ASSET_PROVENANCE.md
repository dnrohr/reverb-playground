# Asset provenance and redistribution

This manifest covers every tracked binary or generated data family in the source archive. Unless a row says otherwise, the assets are original Reverb Playground work, copyright their contributors, and distributed under AGPL-3.0-only with the rest of the project.

| Tracked path family | Contents | Provenance / preferred source | Redistribution |
|---|---|---|---|
| `factory-patches/*.rvp.json` | Editable factory graphs | Original project-authored public-primitive graphs; JSON is the preferred source | AGPL-3.0-only |
| `factory-patches/catalog.json` | Shipped factory identities, versions, family status, license, and provenance | Deterministically generated from `scripts/generate_factory_patches.mjs`; JSON is the preferred manifest | AGPL-3.0-only |
| `schemas/*.json` | Patch JSON Schemas | Original project source | AGPL-3.0-only |
| `src/ui/WebAssets/index.html` | Embedded editor entry point | Generated from `web/index.html` by the pinned web build | AGPL-3.0-only |
| `src/ui/WebAssets/editor.css` | Embedded editor styles | Generated from `web/src/styles.css` plus React Flow's MIT CSS | Project portions AGPL-3.0-only; dependency portion retains MIT |
| `src/ui/WebAssets/editor.js` | Embedded editor JavaScript | Generated from `web/src/**` plus the pinned dependencies in `web/pnpm-lock.yaml` | Project portions AGPL-3.0-only; dependencies retain the terms in `THIRD_PARTY_NOTICES.md` |
| `tests/fixtures/**/*.json` | Golden measurements and invalid/valid graph fixtures | Deterministically generated by project tests/tools or hand-authored project fixtures; JSON is source-readable | AGPL-3.0-only |
| `tests/fixtures/**/*.wav` | Deterministic silence, impulse, and seeded-noise fixtures | Generated by `reverb_render_cli`; generation contract is in `docs/offline-rendering.md` | AGPL-3.0-only |

| `artifacts/audio/**/*.wav` | Reviewed factory-patch renders | Deterministically generated from checked-in factory graphs; adjacent JSON records the render | AGPL-3.0-only |
| `artifacts/ui/**/*.png`, `*.jpg`, `*.gif`, `*.mp4` | Development acceptance evidence | Screen captures made by project contributors from local builds of Reverb Playground; GIFs are presentation derivatives of the adjacent project-authored MP4 where present; not runtime payload | AGPL-3.0-only |

No downloaded photograph, icon set, sample library, impulse response, font, model output, trademark artwork, BarrVerb file, or MIDIVerb ROM-derived binary is tracked. UI symbols are text/CSS shapes and the application uses system fonts.

## Research and local-output exclusions

The root `.gitignore` excludes `/BarrVerb/`, `/research/sources/`, `/tmp/`, `/build/`, and `/out/`. These locations may contain local research checkouts, copyrighted firmware, generated intermediates, or dependency trees. They are not project source and must never be copied into a release archive.

`scripts/check_repository.py` enforces this manifest by:

1. rejecting tracked paths inside excluded research/output roots;
2. rejecting known ROM/firmware filenames and extensions;
3. requiring every tracked binary or generated-data extension to match a documented path family; and
4. checking a real `git archive` listing when the working tree is at a committed revision.

Release packaging must carry `LICENSE`, this manifest, and `THIRD_PARTY_NOTICES.md`. Any new binary/data family must update this document and the verifier in the same commit.
