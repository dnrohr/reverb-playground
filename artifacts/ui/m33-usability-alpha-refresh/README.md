# M33 alpha.2 UI evidence

`reverb-playground-alpha-2-demo.mp4` is a reproducible 42-second overview of
the M28-M32 user-facing change set. `scripts/create_release_demo.ps1` assembles
the checked and previously reviewed milestone recordings without changing their
timing or interaction content, scales each to 1280 by 720, and adds chapter
labels for:

1. searchable guidance;
2. live nested schematics;
3. state-correct tuning;
4. predictable layout; and
5. safe crash recovery.

The output was inspected as an H.264/yuv420p 1280-by-720 file at representative
frames from all five chapters. The source milestone directories retain the
desktop/minimum screenshots and detailed workflow evidence.
